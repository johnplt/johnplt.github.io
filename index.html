StreamChat NLP — Classification Multilingue Temps Réel & Batch

Python / uv Sentence-Transformers dbt / DuckDB Streamlit / Cloud

Plateforme MLOps permettant de catégoriser automatiquement des messages clients dans plus de 50 langues. Conçue pour offrir un traitement rapide et léger sur CPU, sans la latence ni les coûts des gros modèles de langage (LLMs).

Points clés de l'architecture :

  • Classification Zero-Shot : Modèle multilingue léger (MiniLM-L12) permettant d'ajouter ou modifier les catégories métiers à la volée sans aucun ré-entraînement.
  • Architecture Hybride (Batch & Online) : Mode temps réel pour les messages unitaires et pipeline dbt / DuckDB pour l'assainissement et la déduplication de volumes historiques.
  • Pragmatique & Économique : Alternative sobre aux APIs LLM payantes, optimisée pour minimiser les coûts d'infrastructure.
  • Industrialisation Modernisée : Environnement géré via uv, conteneurisation Docker et CI/CD automatisée sous GitHub Actions.

DriveLocal — Agent IA d'Arbitrage & Recherche Sémantique SaaS

Plateforme SaaS de recherche de véhicules de location permettant d'aligner les intentions exprimées en langage naturel avec les contraintes budgétaires réelles.

2. Data Science & Impact métier

Études de cas en Data Science : ingénierie de variables, benchmarking d'algorithmes et optimisation de seuils décisionnels pour la détection et la prévision.

Prévision de la demande & optimisation des stocks (Supply Chain)

Python / uv LightGBM SHAP Streamlit / CI-CD

Modèle d'optimisation de stock visant à minimiser le coût financier global (arbitrage invendus vs ruptures).

Points clés de la démarche :

  • Feature Engineering temporel : Création de lags et variables glissantes sans fuite de données (Data Leakage).
  • Modélisation & Benchmarking : Comparaison d'un modèle LightGBM par rapport à une baseline de moyenne mobile.
  • Explicabilité métier : Interprétation fine des facteurs d'influence (saisonnalité, promotions) via SHAP values.
  • Simulateur financier : Dashboard interactif calculant le stock de sécurité (Safety Stock Buffer) optimal pour maximiser le gain net en euros.

AnomalyEngine — Détection d'anomalies & arbitrage financier

Python / uv Scikit-Learn XGBoost / Isolation Forest SHAP

Modèle de détection d'anomalies multi-domaines (Fintech, IoT, SaaS) orienté sur l'optimisation financière du seuil de décision (arbitrage fausses alertes vs anomalies manquées).

Points clés de la démarche :

  • Feature Engineering & Prétraitement : Calcul de métriques glissantes, de volatilité et d'écarts aux comportements nominaux, adaptées à la détection de ruptures de comportement.
  • Modélisation & Benchmarking : Alignement du seuil de probabilité sur le coût réel d'un Faux Négatif (client perdu) vs Faux Positif (campagne inutile).
  • Explicabilité globale & locale : Analyse fine des facteurs déclencheurs d'alertes via SHAP values (Beeswarm plot global et Waterfall plots comparatifs sur cas sains vs anormaux).
  • Arbitrage coût/seuil : Simulation interactive recherchant le seuil de probabilité optimal minimisant la matrice de coûts métier pour maximiser le gain net.
