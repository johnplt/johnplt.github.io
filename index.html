StreamChat NLP — Classification Multilingue Temps Réel & Batch

Python / uv Sentence-Transformers dbt / DuckDB Streamlit / Railway

Plateforme MLOps permettant de catégoriser automatiquement des messages clients dans plus de 50 langues. Conçue pour offrir un traitement rapide et léger sur CPU, sans la latence ni les coûts des gros modèles de langage (LLMs).

Points clés de l'architecture :

  • Classification Zero-Shot : Modèle multilingue léger (MiniLM-L12) permettant d'ajouter ou modifier les catégories métiers à la volée sans aucun ré-entraînement.
  • Architecture Hybride (Batch & Online) : Mode temps réel pour les messages unitaires et pipeline dbt / DuckDB pour l'assainissement et la déduplication de volumes historiques.
  • Pragmatique & Économique : Alternative sobre aux APIs LLM payantes, optimisée pour minimiser les coûts d'infrastructure et l'empreinte carbone.
  • Industrialisation Modernisée : Environnement géré via uv (Rust-based packaging), conteneurisation Docker et CI/CD automatisée sous GitHub Actions.
