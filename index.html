Projets phares

« Ces projets sont nés d'une volonté simple : concevoir des solutions d'IA appliquées à des problèmes du quotidien, en concevant des architectures légères, utiles et directement déployables. »

Chaque application explore un cas d'usage concret où la donnée apporte une valeur mesurable — qu'il s'agisse d'améliorer et automatiser la qualification du support/service client (StreamChat NLP), d'optimiser la recherche sous contrainte de budget (DriveLocal), ou de fluidifier l'accès à la culture par la recommandation sémantique (CineMind). CineMind — Moteur de Recommandation RAG

Python PostgreSQL / pgvector Streamlit uv

Application de recommandation de films basée sur la recherche de similarité vectorielle en langage naturel.

Points clés de l'architecture :

  • Vectorisation des synopsis via embeddings 384 dimensions (all-MiniLM-L6-v2).
  • Stockage et indexation haute performance avec pgvector et index HNSW.
  • Déploiement managé sur **Railway** avec réseau privé consolidé (.railway.internal).
  • Gestion de l'environnement Python optimisée avec uv.

StreamChat NLP — Classification Multilingue Temps Réel & Batch

Python / uv Sentence-Transformers dbt / DuckDB Streamlit / Railway

Plateforme MLOps permettant de catégoriser automatiquement des messages clients dans plus de 50 langues. Conçue pour offrir un traitement rapide et léger sur CPU, sans la latence ni les coûts des gros modèles de langage (LLMs).

Points clés de l'architecture :

  • Classification Zero-Shot : Modèle multilingue léger (MiniLM-L12) permettant d'ajouter ou modifier les catégories métiers à la volée sans aucun ré-entraînement.
  • Architecture Hybride (Batch & Online) : Mode temps réel pour les messages unitaires et pipeline dbt / DuckDB pour l'assainissement et la déduplication de volumes historiques.
  • Pragmatique & Économique : Alternative sobre aux APIs LLM payantes, optimisée pour minimiser les coûts d'infrastructure et l'empreinte carbone.
  • Industrialisation Modernisée : Environnement géré via uv (Rust-based packaging), conteneurisation Docker et CI/CD automatisée sous GitHub Actions.

DriveLocal — Agent IA d'Arbitrage & Recherche Sémantique SaaS

Python / uv FastAPI PostgreSQL / pgvector Streamlit / Docker

Plateforme SaaS de recherche de véhicules de location permettant d'aligner les intentions exprimées en langage naturel avec les contraintes budgétaires réelles. Un agent d'arbitrage ajuste dynamiquement les options de réservation en cas de dépassement.

Points clés de l'architecture :

  • Recherche Vectorielle Multilingue : Embeddings MiniLM-L12 couplés à pgvector pour apparier les besoins clients avec la flotte disponible.
  • Moteur d'Arbitrage Métier : Logique décisionnelle embarquée analysant l'écart budgétaire pour proposer automatiquement des alternatives économiques (retrait d'options, surclassement négocié).
  • Architecture Microservices : Découplage complet API (FastAPI) et Frontend (Streamlit) conteneurisés indépendamment sous Docker.
  • Déploiement Cloud & Auto-Seeding : Pipeline hébergé sur Railway avec initialisation automatique du schéma SQL et injection des embeddings au démarrage.
